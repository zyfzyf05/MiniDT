# MiniDT

一个微型依赖类型语言内核 —— 在 Lean 4 中实现一个小型依赖类型理论的语法、类型检查器与求值器，并形式化证明其元理论性质。

**开发早期，一切从简，长期更新。**

## 为什么是这个项目

1. **时代背景**：2026 年以来，OpenAI 等前沿实验室开始用 AI 批量产出数学研究成果（如 openai/math 仓库中的数百篇手稿）。这批成果之所以能被认真对待，是因为其中通过验证的部分都经受了 Lean 这类形式化验证内核的逐行机器检查。**形式化验证正在成为 AI 时代数学与软件的信任基础设施。**
2. **项目本体**：MiniDT 就是亲手重建这个"信任锚点"的最小实现——不靠黑箱地理解：一个证明助手内核究竟如何保证"每一步都合法"。
3. **个人动机**：在复现 TransUNet 时遭遇过张量形状错配这一类错误。依赖类型理论最直觉的应用，就是把矩阵维度编码进类型，让不匹配的运算在类型检查阶段就不可能通过。本项目将演示这一点。
4. **学脉所在**：从唐稚松先生开创的时序逻辑程序设计，到今天中国科学院软件研究所计算机科学国家重点实验室的形式化方法研究，依赖类型与程序验证在这里是家学。
